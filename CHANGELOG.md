# Changelog

All notable changes to CeloHT's documentation are recorded here, following [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-08-01

### Added
- Initial public documentation release
- Core reference documents: `README.md`, `LITEPAPER.md`, `WHITEPAPER.md`
- Pillar documentation: `EDUCATION.md`, `AGENT_NETWORK.md`, `REFORESTATION.md`
- Technical documentation: `ARCHITECTURE.md`, `SMART_CONTRACTS.md` (reference specification + illustrative test suite), `DAPP.md`, `API_REFERENCE.md`, `DEVELOPER_GUIDE.md`
- Governance & policy documentation: `GOVERNANCE.md`, `NO_TOKEN_POLICY.md`, `LEGAL_STATUS.md`, `SECURITY.md`
- Community documentation: `PARTNERS.md`, `METRICS.md`, `ROADMAP.md`, `FAQ.md`, `GLOSSARY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`
- CI workflow validating all Markdown links and formatting on every PR

### Notes
This is the foundation release. `SMART_CONTRACTS.md` and `DAPP.md` contain **reference specifications**, not confirmed live deployment status — see the status notices at the top of each document. All other documents describe current CeloHT policy, governance, and program design.
