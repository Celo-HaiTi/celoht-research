# Events

## Event Types

| Type | Purpose |
|---|---|
| Community workshops | Direct education delivery (see [EDUCATION.md](./EDUCATION.md)), typically facilitated with Agent Network support |
| Hackathons | Developer engagement, sourced contributions, ecosystem visibility |
| Conference talks | Broader visibility with NGOs, universities, developer communities |
| Partner/NGO events | Joint outreach with partner organizations (see [PARTNERS.md](./PARTNERS.md)) |

## Hosting a CeloHT Event

1. Propose via issue or contact contact@celoht.com, tagging the relevant Working Group
2. For education-focused events: Education Working Group reviews content plan
3. For hackathons/developer events: Engineering Working Group provides technical support materials
4. Branding follows the Brand repository's `EVENT_BRANDING.md`

## Speaking on Behalf of CeloHT

Only designated Working Group members, ambassadors (see [AMBASSADOR_PROGRAM.md](./AMBASSADOR_PROGRAM.md)), or the founder should present official CeloHT positions at events. All speakers should be able to accurately explain the No-Token Policy — see [NO_TOKEN_POLICY.md](./NO_TOKEN_POLICY.md) — as this is frequently the first question from new audiences given Web3's broader reputation.

## Hackathon Participation

CeloHT welcomes hackathon teams building on its open-source stack. Suggested starter issues are tagged `good-first-issue` and `hackathon-friendly` across CeloHT repositories. See [DEVELOPER_GUIDE.md](./DEVELOPER_GUIDE.md) to get started.

## Event Materials

Presentation templates, banners, and booth materials follow the Brand repository's `PRESENTATION_GUIDE.md` and `EVENT_BRANDING.md`.
