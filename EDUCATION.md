# Education

## Purpose

Education is the entry point to every other CeloHT pillar. No one should be asked to use a financial tool they don't understand. This document defines CeloHT's educational programs, audiences, curriculum structure, and delivery model.

## Audiences & Programs

| Audience | Program focus |
|---|---|
| Individuals | Financial literacy basics, digital security, how to use a wallet safely |
| Communities | Group workshops, in-person or via Agent Network, focused on trust-building and Q&A |
| Schools | Age-appropriate financial and digital literacy curriculum, delivered with partner educators |
| NGOs | Train-the-trainer programs so partner staff can deliver CeloHT education independently |
| Developers | Technical onboarding to CeloHT's open-source stack — see [DEVELOPER_GUIDE.md](./DEVELOPER_GUIDE.md) |
| Entrepreneurs | Using digital payments for small business, cross-border payments, basic bookkeeping |
| Governments | Policy-level briefings on CeloHT's model, no-token policy, and regulatory posture |

## Curriculum Modules

Each module below has a full, detailed lesson plan in [`education/`](./education/), including learning objectives, lesson-by-lesson content, and assessment criteria for facilitators.

1. **[Digital & Financial Literacy Foundations](./education/module-01-financial-literacy-foundations.md)** — budgeting, saving, understanding fees and value
2. **[Introduction to Web3 & Blockchain](./education/module-02-web3-and-blockchain.md)** — plain-language explanation of what a blockchain is and isn't
3. **[Understanding cUSD and CELO](./education/module-03-cusd-and-celo.md)** — what they are, how they differ, why cUSD is used for payments and CELO only for gas
4. **[Using Valora Safely](./education/module-04-wallet-safety.md)** — wallet setup, seed phrase security, transaction verification
5. **[Digital Security](./education/module-05-digital-security.md)** — phishing awareness, scam recognition (including fake "CeloHT token" scams — see [NO_TOKEN_POLICY.md](./NO_TOKEN_POLICY.md)), device security
6. **[Responsible Digital Finance](./education/module-06-responsible-digital-finance.md)** — understanding that CeloHT is not an investment, includes entrepreneur/small-business extension content and a conceptual DeFi-basics lesson
7. **[Using the Agent Network](./education/module-07-using-the-agent-network.md)** — how to find, verify, and safely transact with a local agent
8. **[Developer Onboarding Track](./education/module-08-developer-onboarding.md)** — technical track for open-source contributors, parallel to Modules 1–7

## Delivery Model

- **Primary language:** Haitian Creole for all direct community-facing material
- **Formats:** in-person workshops (often facilitated by Agent Network members), short-form video, printed materials for low-connectivity areas, and app-based micro-lessons
- **Train-the-trainer:** partner organizations (NGOs, schools) are equipped to deliver CeloHT curriculum independently, extending reach beyond CeloHT's direct capacity

## Localization

All community-facing educational content is authored natively in Haitian Creole first, not translated from English or French — see the CeloHT Brand repository's `VOICE_AND_TONE.md` for language principles. Technical documentation (this repository) is maintained in English as the reference language for the global contributor and partner community.

## Measuring Effectiveness

Education outcomes are tracked via: workshop completions, micro-lesson completion rates, pre/post assessment score changes, and downstream indicators (e.g. reduced scam-reporting incidents in trained communities). See [METRICS.md](./METRICS.md).

## How to Contribute

Educators, translators, and curriculum designers can contribute via [CONTRIBUTING.md](./CONTRIBUTING.md). The Education Working Group (see [GOVERNANCE.md](./GOVERNANCE.md#working-groups)) reviews all new curriculum content before publication.
