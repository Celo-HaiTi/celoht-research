# User Guide

## Getting Started

### 1. Get a Wallet
Install **Valora** (see [VALORA.md](./VALORA.md)) — the wallet CeloHT's education and Agent Network materials are built around.

### 2. Learn the Basics (Optional but Recommended)
Complete the first CeloHT education module before your first transaction — it takes about 15 minutes and covers what cUSD is, how CeloHT works, and how to stay safe. See [EDUCATION.md](./EDUCATION.md).

### 3. Connect Your Wallet
Open the CeloHT dApp and select "Connect Wallet." Follow your wallet app's confirmation prompt. See [DAPP.md](./DAPP.md#wallet-connection) for the technical flow.

### 4. Find an Agent (for cash-in/cash-out)
Use the in-app agent directory to find a verified Agent Network member near you. Every listed agent is verified against the on-chain [AgentRegistry](./SMART_CONTRACTS.md#agentregistry--reference-specification) — look for the "Verified" badge before transacting.

## Sending and Receiving Money

**To receive:** tap "Receive," show your QR code to the sender (works even without an internet connection once loaded).

**To send:** tap "Send," scan the recipient's QR code or enter their address, confirm the amount, and approve the transaction in your wallet app.

## Using an Agent (Cash-In / Cash-Out)

1. Locate a verified agent via the in-app directory
2. Agree on the amount in person
3. Confirm the transaction in the app — both you and the agent will see a matching confirmation before exchanging cash/digital funds
4. Never complete a cash exchange before both confirmations match on-screen

## Staying Safe

- CeloHT will **never** ask for your seed phrase or wallet password — see [SECURITY.md](./SECURITY.md#wallet-safety)
- CeloHT has **no token** — anything claiming otherwise is fraudulent, see [NO_TOKEN_POLICY.md](./NO_TOKEN_POLICY.md#reporting-violations)
- Only transact with agents showing the "Verified" badge
