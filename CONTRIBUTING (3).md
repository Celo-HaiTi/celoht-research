# Contributing to the CeloHT Brand Repository

Thank you for helping build CeloHT's visual identity. This repository is community-governed — no single person, including the founder, unilaterally decides what CeloHT looks like. Changes are made through discussion, review, and consensus.

## What You Can Contribute

- New brand documentation (e.g. iconography, illustration, social media, presentation, press kit guides)
- New logo file formats or sizes that follow existing specifications exactly
- Corrections to color values, contrast ratios, or typography specs
- Translations of brand documents into Haitian Creole, French, or other languages
- Improvements to clarity, accessibility, or completeness of existing docs

## What Requires Extra Review

- Any change to the CeloHT logo itself (the mark, not just file format)
- Any change to the primary color palette
- Any change to the non-affiliation disclaimer wording
- Anything that touches how CeloHT represents its relationship to Celo or Valora

These require sign-off from at least two community maintainers, because they affect legal clarity and public trust.

## How to Propose a Change

1. Open an issue describing what you want to add or change and why.
2. For visual assets, include a preview (image or link) — not just a description.
3. Wait for at least one maintainer response before submitting a pull request; this avoids duplicated work.
4. Submit a pull request referencing the issue.
5. A maintainer will review against the standards in [BRAND_GUIDE.md](./BRAND_GUIDE.md).

## Standards for New Documents

Every new brand document must:

- Be complete — no "TODO" sections or placeholder text
- Include concrete examples, not just abstract rules
- Be usable by someone with no prior design background
- Follow the existing file naming and structure conventions
- Include accessibility considerations where relevant (contrast, screen readers, color blindness)

## File Naming Conventions

Logo files: `celoht-logo-[variant]-[color]-[format].[ext]`

Examples:
- `celoht-logo-horizontal-full-color.svg`
- `celoht-logo-icon-monochrome-black.png`
- `celoht-logo-vertical-white.svg`

## Code of Conduct

All contributors are expected to communicate respectfully and assume good faith, in any language. Disagreements about design direction should be resolved through discussion referencing the principles in [BRAND_GUIDE.md](./BRAND_GUIDE.md), not personal preference alone.

## Questions?

Open an issue, or reach out at contact@celoht.org.
