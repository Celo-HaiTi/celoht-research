# Open Questions: Financial Inclusion

- Does agent-mediated cash-in/cash-out usage translate into independent digital transaction behavior over time, or does dependency on the agent persist indefinitely?
- What specific, named barriers (not just "lack of trust" generically) stop trained individuals from adopting?
- How does household financial resilience change, if at all, with sustained CeloHT program access?
- Are there demographic groups within pilot communities being systematically under-reached, and why?
- How does CeloHT's model compare, in cost and outcome, to existing informal savings/lending structures (e.g. *sòl*) already used in Haitian communities?

Proposals addressing any of these are welcome — see [../../RESEARCH_GUIDELINES.md](../../RESEARCH_GUIDELINES.md#proposing-new-research).
