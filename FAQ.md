Frequently Asked Questions

General

What is CeloHT?
CeloHT is a Haitian-led, open-source Web3 initiative focused on financial inclusion, blockchain education, digital payments, and entrepreneurship within the Celo ecosystem. Its three permanent pillars are Education, Agents, and Reforestation. See "LITEPAPER.md" (./LITEPAPER.md).

Is CeloHT a cryptocurrency or token?
No. CeloHT is not a cryptocurrency, blockchain, or token. It has no native CeloHT token, no ICO, no presale, and no investment product. CeloHT uses existing Celo ecosystem infrastructure, including CELO for network gas and USDm for supported stable-value payment flows. See "NO_TOKEN_POLICY.md" (./NO_TOKEN_POLICY.md).

Is CeloHT affiliated with Celo Foundation, Valora, MiniPay, or WalletConnect?
No. CeloHT uses the Celo blockchain and supports multiple compatible wallet access methods as technical infrastructure choices. CeloHT is independently operated and community-governed.

CeloHT is not officially affiliated with, endorsed by, sponsored by, or operated by the Celo Foundation, Valora, MiniPay, WalletConnect, Opera, or their respective developers.

See "LEGAL_STATUS.md" (./LEGAL_STATUS.md).

Who founded CeloHT?
Johnny Dubic founded CeloHT. CeloHT is community-governed, and the founder does not unilaterally control community decisions. See "GOVERNANCE.md" (./GOVERNANCE.md).

Using CeloHT

Do I need to already understand blockchain to use CeloHT?
No. The Education pillar exists specifically to introduce blockchain, digital payments, wallet safety, and related concepts from the ground up, primarily in Haitian Creole. See "EDUCATION.md" (./EDUCATION.md).

How do I convert cash to digital money?
Where the service is available, users can interact with verified CeloHT Agents through the dApp's Agent Network. Agent availability and transaction services depend on the current local program and participating agents. See "AGENT_NETWORK.md" (./AGENT_NETWORK.md).

Which wallets does CeloHT support?
CeloHT follows a wallet-agnostic strategy and does not require users to use one specific wallet provider.

The current documented wallet integrations include:

- MiniPay, when the dApp is opened inside MiniPay
- Valora, through WalletConnect
- Other compatible mobile wallets, through WalletConnect or another supported wallet integration

Actual wallet availability can vary by device, wallet provider, network configuration, and the current dApp integration. See "DAPP.md" (./DAPP.md#wallet-connection) and the dApp wallet documentation.

Does CeloHT require a specific wallet?
No. CeloHT does not require users to use Valora, MiniPay, or any other single wallet provider. The goal is to maintain a wallet-agnostic architecture so users can access the dApp through supported compatible wallet integrations.

Does CeloHT support MiniPay?
Yes. MiniPay is supported when the CeloHT dApp is opened inside the MiniPay environment and provides an available injected wallet provider. Other compatible wallets can use the documented WalletConnect integration where available.

Does CeloHT support WalletConnect?
Yes. WalletConnect is used to connect Valora and other compatible mobile wallets where the current CeloHT dApp integration supports them.

What assets does CeloHT use?
CeloHT's financial functionality is built on the Celo ecosystem. USDm is the current stable-value asset referenced for supported payment flows, while CELO may be used for Celo network gas and other network-level functions.

CeloHT does not issue a native token.

Will CeloHT ever ask for my seed phrase or private key?
Never, under any circumstance.

CeloHT will never ask users to provide:

- Seed phrases
- Private keys
- Wallet passwords

All transaction approvals and signatures must remain inside the user's selected wallet. Any person or website claiming to represent CeloHT and requesting these credentials should be treated as fraudulent.

See "SECURITY.md" (./SECURITY.md#wallet-safety).

Becoming an Agent

How do I become a CeloHT Agent Network member?
See the lifecycle and requirements in "AGENT_NETWORK.md" (./AGENT_NETWORK.md#agent-lifecycle). Registration begins through the dApp's Agent onboarding flow when the relevant functionality is available.

How are agents compensated?
Where an Agent Network fee model is active, compensation is based on a transparent, published transaction fee denominated in USDm or another explicitly documented payment asset. CeloHT does not use a native token for agent rewards.

See "AGENT_NETWORK.md" (./AGENT_NETWORK.md#revenue-model).

Does becoming a CeloHT Agent mean I am an employee of CeloHT?
No. Agent participation is part of the CeloHT ecosystem and does not by itself establish an employment relationship. Specific legal, operational, and compliance requirements depend on the applicable program and jurisdiction.

Education & Reforestation

What does the Education pillar provide?
The Education pillar provides accessible learning resources covering blockchain, digital finance, wallet safety, Celo, digital payments, and related Web3 concepts. Content is designed to be understandable to users with limited or no previous blockchain experience. See "EDUCATION.md" (./EDUCATION.md).

How does CeloHT support reforestation?
The Reforestation pillar supports tree-financing and planting initiatives through the CeloHT ecosystem. Where a reforestation program is active, contributions and planting records should be documented transparently and associated with the relevant program or verification process. See "REFORESTATION.md" (./REFORESTATION.md).

Can I contribute to reforestation using USDm?
Where the relevant contribution flow is enabled, USDm can be used for supported reforestation contributions. CeloHT does not represent a contribution as a planted tree unless the corresponding program records and verification requirements support that claim.

Contributing & Partnering

Can I contribute code even if I'm not in Haiti?

How can my organization partner with CeloHT?
See "PARTNERS.md" (./PARTNERS.md#how-to-propose-a-partnership).

Yes. CeloHT may accept donations, grants, or other lawful forms of funding denominated in fiat or supported digital assets such as USDm, subject to applicable governance, treasury, legal, and reporting requirements. Funding should be transparently associated with its intended purpose or program where applicable.

Can companies or developers build on CeloHT?

Governance

Who controls CeloHT's decisions?
CeloHT is community-governed. No single individual is intended to unilaterally control major community decisions.

Depending on the type and importance of a proposal, decisions may go through public discussion, RFC processes, Working Groups, maintainers, and other governance mechanisms defined in "GOVERNANCE.md" (./GOVERNANCE.md).

Is the founder the CEO of CeloHT?
No. The founder role does not mean unilateral executive control over the community or its governance.

Can the No-Token Policy ever change?
The current policy establishes that CeloHT has no native token and does not operate a token sale, ICO, presale, or investment product.

Any future amendment to the policy would have to follow the formal governance process defined in "NO_TOKEN_POLICY.md" (./NO_TOKEN_POLICY.md#policy-amendment-process). Until such an amendment is formally approved, the existing No-Token Policy remains in force.

Trust & Safety

I saw a "CeloHT token" being promoted somewhere — is it real?
No. CeloHT has no native token.

Any website, account, contract, or person claiming to sell a "CeloHT token," conduct a CeloHT token presale, or offer CeloHT investment opportunities is not authorized by this policy.

Report suspected violations through the contact method documented in "NO_TOKEN_POLICY.md" (./NO_TOKEN_POLICY.md#reporting-violations).

Does CeloHT offer investment opportunities?
No. CeloHT is not an investment product and does not promise financial returns from participation, donations, agent activity, education, reforestation, or use of the CeloHT ecosystem.

How is my data protected?
CeloHT's architecture is designed so that personally identifiable information is not stored directly on the blockchain. Application data may be handled by off-chain infrastructure where required for the operation of specific services and subject to the applicable privacy and security policies.

Users should never submit private keys, seed phrases, or wallet passwords to CeloHT or any service claiming to represent CeloHT.

See "LEGAL_STATUS.md" (./LEGAL_STATUS.md#privacy) and "SMART_CONTRACTS.md" (./SMART_CONTRACTS.md#design-principles).

Can transactions on Celo be reversed by CeloHT?
No. Blockchain transactions confirmed on the Celo network are not generally reversible by CeloHT. Users should carefully verify wallet addresses, amounts, network, and transaction details before signing.

Current Product Status

Is the CeloHT dApp live?
The CeloHT dApp is deployed and testable on Celo Sepolia with core wallet and smart-contract integration implemented.

Production Mainnet rollout remains dependent on verified Mainnet deployments, backend and indexer production readiness, security review, and end-to-end validation.

See "DAPP.md" (./DAPP.md).

Does CeloHT currently support Celo Mainnet?
CeloHT documentation and infrastructure may reference Celo Mainnet as the intended production network, but a feature should only be considered production-ready when the relevant deployment, contract addresses, configuration, backend services, and end-to-end tests have been verified.

See "SUPPORTED_NETWORKS.md" (./SUPPORTED_NETWORKS.md).
