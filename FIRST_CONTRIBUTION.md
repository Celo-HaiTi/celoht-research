# Your First Contribution

## Non-Code Ways to Start

You don't need to write code to contribute meaningfully:
- Fix a typo or unclear sentence in any `.md` file
- Translate a document (see [TRANSLATION_GUIDE.md](./TRANSLATION_GUIDE.md))
- Answer a question in [GitHub Discussions](https://github.com/Celo-HT/CeloHT/discussions)
- Report a documentation gap as an issue

## Code Contributions

1. Find an issue tagged `good-first-issue` in the relevant repository (dApp, Smart-Contracts, Website)
2. Read [DEVELOPER_GUIDE.md](./DEVELOPER_GUIDE.md) for setup
3. Fork, branch, and follow [CODING_STANDARDS.md](./CODING_STANDARDS.md)
4. Open a PR using the repository's PR template

## What Happens After You Submit

A maintainer reviews your PR against [DEVELOPER_GUIDE.md](./DEVELOPER_GUIDE.md#code-review) — expect questions and requested changes; that's normal, not rejection. Once merged, you're recognized in [AUTHORS.md](./AUTHORS.md).

## If You Get Stuck

Ask in [GitHub Discussions](https://github.com/Celo-HT/CeloHT/discussions) or reference [SUPPORT.md](./SUPPORT.md) — there's no such thing as a bad first-contribution question.
