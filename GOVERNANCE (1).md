# Governance

This is an organization-wide summary of how CeloHT makes decisions. For the full, detailed policy, see the main documentation repository's [`GOVERNANCE.md`](https://github.com/Celo-HT/CeloHT/blob/main/GOVERNANCE.md) — this document should always match it; if you spot a difference, please [open an issue](https://github.com/Celo-HT/.github/issues/new/choose).

## Structure

```
Foundation Director → Maintainer Council → Community Contributors
```

| Role | Responsibility |
|---|---|
| **Foundation Director** | Strategic vision, external representation, final call in a genuine deadlock |
| **Maintainer Council** | Technical review, PR approval, day-to-day repository management |
| **Community Contributors** | Issues, pull requests, discussions — the entry point to the Maintainer Council |

The Foundation Director does not hold unilateral authority over funds, policy, or roadmap — proposed changes go through the same review process as any other proposal for major or governance-level decisions.

## Decision-Making

- **Minor changes** (typos, clarity fixes) — any maintainer, standard review
- **Major changes** (structural, policy, brand) — Maintainer Council consensus, discussed publicly first
- **Governance changes** — minimum 14-day public comment period, majority Council approval

## Toward Decentralization

CeloHT's governance is designed to evolve: a lightweight elected community input process in Phase 3 of the roadmap, moving toward a more formally decentralized model in Phase 4. See the main documentation repository's [`ROADMAP.md`](https://github.com/Celo-HT/CeloHT/blob/main/ROADMAP.md#phase-4--maturity-2028) for the specific commitments.

## No Token, No Token-Weighted Voting

CeloHT has no native token and never will — see [`NO_TOKEN_POLICY.md`](https://github.com/Celo-HT/CeloHT/blob/main/NO_TOKEN_POLICY.md). Governance participation is based on contribution, not holdings.

## Applies Across All Repositories

This governance model applies uniformly across every repository in the CeloHT organization — [CeloHT](https://github.com/Celo-HT/CeloHT), [celoht-research](https://github.com/Celo-HT/celoht-research), [Brand](https://github.com/Celo-HT/Brand), and this `.github` repository.
