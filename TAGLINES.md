# CeloHT Taglines

## Primary Tagline

**"Financial inclusion, built with community."**

Use this as the default tagline anywhere a single line accompanies the logo — website hero, social bios, email signatures, presentation title slides.

## Secondary Taglines (context-specific)

| Context | Tagline |
|---|---|
| Education-focused content | "Learn first. Grow together." |
| Agent Network content | "Real people, real access." |
| Reforestation content | "Growing communities, growing forests." |
| Developer / open-source content | "Open source. Open community. Open future." |
| General impact / press | "Education, access, and sustainability — for Haiti, built by Haiti." |

## Haitian Creole

**"Enklizyon finansye, bati ak kominote a."** *(Financial inclusion, built with community.)*

## French

**« L'inclusion financière, construite avec la communauté. »**

## Usage Rules

- Taglines pair with the logo but are never embedded inside the logo file itself — always set as separate typography (Fraunces italic or IBM Plex Sans, per [TYPOGRAPHY.md](./TYPOGRAPHY.md))
- Never alter the wording of the primary tagline — secondary taglines may be used contextually but should not replace the primary tagline on flagship materials (README, homepage, official press kit)
- Taglines must never imply financial return ("grow your money") — "grow" in CeloHT taglines always refers to community, education, or environmental growth
