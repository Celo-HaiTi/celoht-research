# Economics Research

**Summary:** Economic impact analysis of CeloHT's programs, and modeling for long-term financial sustainability.
**Purpose:** Quantify real economic effects, and test whether the Agent Network fee model can actually reach self-sustainability.
**Scope:** Household-level economic impact, Agent Network economics, program cost-effectiveness.
**Audience:** Maintainer Council, funders, researchers.

## Overview

CeloHT's economic claims run in two directions: the impact it has on participating households, and its own path toward reduced grant dependence (see the main documentation repository's `BUSINESS_MODEL.md` and `FUNDING_POLICY.md`). Both need real modeling, not assumption.

## Research Questions

1. What measurable economic effect does sustained CeloHT participation have on household financial resilience?
2. What per-transaction fee level makes the Agent Network genuinely self-sustaining without pricing out the users it exists to serve?
3. What is the true cost-per-outcome (cost per person trained, per active agent, per verified surviving tree) across pillars, and how does it trend as the program scales?

## Objectives

Ground both CeloHT's impact claims and its financial-sustainability roadmap (see the main documentation repository's `ROADMAP.md#phase-3--growth-2027`) in real numbers.

## Current Knowledge

Foundational stage.

## Data Sources

Program cost data, Agent Network transaction and fee data, planned household economic survey.

## Methodology

## Limitations

Cost-effectiveness figures from a single pilot region may not hold at scale; explicitly flagged as pilot-stage estimates until validated further.
