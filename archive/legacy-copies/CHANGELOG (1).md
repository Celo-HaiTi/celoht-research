# Changelog

All notable changes to CeloHT Research are documented here, following [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-08-02

### Added
- Initial public structure for CeloHT Research
- Core policy documents: RESEARCH_ROADMAP, RESEARCH_GUIDELINES, RESEARCH_ETHICS, PEER_REVIEW, PUBLICATION_POLICY, OPEN_SCIENCE, REPRODUCIBILITY, CITATION_GUIDE, STYLE_GUIDE, METHODOLOGY, DATA_POLICY, QUALITY_ASSURANCE, FIELD_RESEARCH, STATISTICS, RESEARCH_CHECKLIST, CONTRIBUTING
- 16 research area folders with standard README structure
- Document templates: research, report, whitepaper, working paper
- GitHub configuration: research proposal and paper proposal issue templates, PR template, CODEOWNERS, CI validation workflow
- validate.sh local validation script

### Notes
This is the foundation release. Research areas are structured and scoped but do not yet contain completed findings — see [RESEARCH_ROADMAP.md](./RESEARCH_ROADMAP.md) for what's planned and when, consistent with this repository's own standard of not claiming research results before they exist.
