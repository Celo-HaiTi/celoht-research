# Research Checklist

**Summary:** Self-check for authors before requesting peer review.
**Purpose:** Catch the common, avoidable problems before a reviewer's time is spent on them.
**Scope:** All submissions.
**Audience:** Authors.

## Before Submitting for Review

- [ ] The research question is stated explicitly in the first section
- [ ] Method is described in enough detail that someone else could repeat it
- [ ] Data source(s) are named and, if not published in full, the reason is stated (see [DATA_POLICY.md](./DATA_POLICY.md#what-is-not-published))
- [ ] Limitations section is present and specific, not a generic disclaimer
- [ ] Every quantitative claim has a number, unit, and date
- [ ] No claim implies CeloHT is, or should become, an investment or token-issuing entity
- [ ] Findings that reflect unfavorably on a CeloHT program are included, not softened or omitted
- [ ] Citations follow [CITATION_GUIDE.md](./CITATION_GUIDE.md)
- [ ] Document follows the structure in [STYLE_GUIDE.md](./STYLE_GUIDE.md)
- [ ] If human-subject data is involved, ethics review is complete per [RESEARCH_ETHICS.md](./RESEARCH_ETHICS.md)
- [ ] Analysis code and data are included or linked, per [REPRODUCIBILITY.md](./REPRODUCIBILITY.md)
- [ ] Conflicts of interest are disclosed, if any

## Before Requesting Publication (Post-Review)

- [ ] All reviewer comments addressed or explicitly discussed to resolution
- [ ] CeloHT Research identifier assigned (see [CITATION_GUIDE.md](./CITATION_GUIDE.md#celoht-research-identifiers))
- [ ] Entry added to the relevant `research/<area>/findings/` index
