# Contributing to CeloHT Research

Thank you for considering a contribution. This repository welcomes research contributions from CeloHT maintainers, academic partners, independent researchers, and community members alike.

## Ways to Contribute

- **Propose new research** — open an issue with the Research Proposal template
- **Contribute to an existing research area** — check `research/<area>/open-questions.md` for known gaps
- **Review a submission** — see [PEER_REVIEW.md](./PEER_REVIEW.md)
- **Report an issue with published research** — see [OPEN_SCIENCE.md](./OPEN_SCIENCE.md#community-critique)
- **Improve documentation, templates, or tooling** — smaller contributions are just as welcome as full studies

## Before You Start

1. Read [RESEARCH_GUIDELINES.md](./RESEARCH_GUIDELINES.md) for the full workflow
2. Read [RESEARCH_ETHICS.md](./RESEARCH_ETHICS.md) if your work involves people or their data
3. Check for existing or in-progress work on your question, to avoid duplication

## Submission Standards

Every submission must be complete — no placeholder sections, no "findings TBD." See [RESEARCH_CHECKLIST.md](./RESEARCH_CHECKLIST.md) before requesting review.

## Code of Conduct

This repository follows the main documentation repository's `CODE_OF_CONDUCT.md`. Disagreement about methodology or findings is normal and welcome; disrespect toward contributors is not.

## Recognition

Contributors are credited per [PUBLICATION_POLICY.md](./PUBLICATION_POLICY.md#authorship--attribution) and recognized in the main documentation repository's `AUTHORS.md`.

## Questions

Open a discussion, or email research@celoht.com.
