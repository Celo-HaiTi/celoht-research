# Translation Guide

## Language Strategy

| Content type | Primary language | Notes |
|---|---|---|
| Technical documentation (this repository) | English | Reference language for global contributors — see [CONTRIBUTING.md](./CONTRIBUTING.md#language-policy) |
| Direct community education content | Haitian Creole | Authored natively, not translated — see [EDUCATION.md](./EDUCATION.md#localization) |
| Press/partnership materials | English + French | French for regional/international partner reach |
| dApp UI | Haitian Creole (default), English, French | See [DAPP.md](./DAPP.md#localization) |

## Why Native Authoring, Not Just Translation

Machine or literal translation of financial and technical concepts frequently loses precision or introduces confusing phrasing — a real risk when the audience includes first-time financial-tool users. Haitian Creole education content is written directly by fluent speakers with subject knowledge, not translated word-for-word from English drafts.

## Translating Technical Documentation

Should this English-language documentation be translated into French or another reference language (e.g. for a specific partner or regulatory need):

1. Translate meaning, not literal phrasing — especially for terms defined in [GLOSSARY.md](./GLOSSARY.md)
2. Preserve all cross-links, updating them to point to the translated document if a full translated set exists, or back to the English original otherwise
3. Never translate [NO_TOKEN_POLICY.md](./NO_TOKEN_POLICY.md) without Governance & Legal Working Group review — precision here has legal and trust implications
4. Mark translated documents clearly with the source document's version (see [CHANGELOG.md](./CHANGELOG.md)) so translations can be flagged as outdated when the English source changes

## Terminology Consistency

Maintain a single glossary of approved translations for key terms (cUSD, Agent Network, No-Token Policy, etc.) rather than letting each translator choose independently — coordinate through the Education Working Group for community-facing terms and the Governance & Legal Working Group for policy terms.

## Contributing a Translation

See [CONTRIBUTING.md](./CONTRIBUTING.md). Translation contributions go through the same completeness standard as original content — a partial translation is not merged as-is.
