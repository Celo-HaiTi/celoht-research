# Impact

## Purpose

This document frames CeloHT's impact model conceptually — how the three pillars translate into real outcomes. For live numbers and methodology detail, see [METRICS.md](./METRICS.md).

## Theory of Change

```
Education  ──────►  Understanding & Trust
                            │
                            ▼
Agent Network ────►  Real, Safe Access to Digital Payments
                            │
                            ▼
                    Improved Financial Resilience
                    (savings, cross-border remittance,
                     small business payments)
                            │
Reforestation ────►  Environmental Co-Benefit
                     (without this, "development" is incomplete)
                            │
                            ▼
              Durable, Trusted, Locally-Owned Progress
```

Each arrow represents a claim CeloHT is accountable for demonstrating with data — not an assumption. See [METRICS.md](./METRICS.md#methodology-principles) for how each is measured and what would falsify it.

## Impact by Pillar

**Education:** measured via training completions and, more importantly, downstream safety indicators (reduced scam susceptibility, correct usage of security practices). See [EDUCATION.md](./EDUCATION.md#measuring-effectiveness).

**Agent Network:** measured via active agents, transaction volume as a proxy for genuine economic utility (not speculation), and user satisfaction. See [AGENT_NETWORK.md](./AGENT_NETWORK.md#performance-metrics).

**Reforestation:** measured via verified tree survival (not just planting counts), hectares under monitoring, and community nursery sustainability. See [REFORESTATION.md](./REFORESTATION.md#impact-measurement).

## What CeloHT Does Not Claim

CeloHT does not claim to have solved financial exclusion in Haiti, nor does it present preliminary metrics as proof of large-scale transformation. Impact claims are scoped precisely to what the data shows, with methodology disclosed alongside every figure — see [METRICS.md](./METRICS.md#corrections-policy) for how CeloHT handles measurement errors transparently.

## Independent Verification

Where feasible, CeloHT invites independent researchers and partner NGOs/universities to verify impact claims — see [PARTNERS.md](./PARTNERS.md) and [RESEARCH.md](./RESEARCH.md).
