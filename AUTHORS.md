# Authors & Contributors

CeloHT exists because of its community. This file recognizes those who have contributed meaningfully to the project — code, documentation, education content, translation, governance, or field operations.

## Maintainers

Current maintainers, by Working Group (see [GOVERNANCE.md](./GOVERNANCE.md#working-groups)), are published and kept current in each repository's `MAINTAINERS.md` or repository settings, since maintainer status can change more frequently than this document is reviewed. This file tracks recognition of contribution; repository-level maintainer lists remain the source of truth for current commit/merge access.

## How to Be Recognized Here

Contributors are added to this file after a merged, substantive contribution — code, documentation, translation, curriculum design, or sustained community facilitation. Open a PR adding your name (or handle, if you prefer) under the appropriate category below, referencing the contribution. See [CONTRIBUTING.md](./CONTRIBUTING.md).

## Note on This List

Unlike other documents in this repository, this file is intentionally incremental by nature — it grows as real contributions are merged, rather than being "complete" on day one. This is standard open-source practice (compare to any mature project's `AUTHORS` file) and does not conflict with this repository's no-placeholder standard: an empty category is not a placeholder, it is an accurate reflection of contribution history to date.
