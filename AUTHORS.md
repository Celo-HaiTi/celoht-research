## 2. Contributors

As of this document's publication date, CeloHT's contributor base beyond the Founder is in early formation. This document does not list additional named contributors until they have made a recorded, attributable contribution to a CeloHT repository (a merged pull request, an accepted documentation change, or an equivalent recorded artifact).

CeloHT does not pre-populate this list with anticipated, invited, or informal contributors. Entries are added only after a contribution has actually been made and recorded in project history (typically via Git commit history or a repository's pull request record).

**Contributor list format**, once populated, will follow:

| Name / Handle | Type of Contribution | Repository | Date of First Contribution |
|---|---|---|---|
| *(to be populated as contributions are recorded)* | | | |

Contributors may choose to be listed by their legal name, a consistent public handle (e.g., their GitHub username), or to opt out of individual listing entirely while still being credited in aggregate commit history, consistent with the privacy considerations in `VERIFICATION_POLICY.md`.

## 3. Recognition Policy

CeloHT recognizes contributions in proportion to their nature and impact, following practices common to major open-source foundations:

- **Code and documentation contributions** are recognized through Git commit history (the authoritative record) and, where the contributor consents, through a listing in this document.
- **Sustained contributions** may lead to nomination for a Maintainer role, per the process in `MAINTAINERS.md`.
- **Non-code contributions** (translation, community moderation, event support, reforestation fieldwork) are recognized through `CONTRIBUTORS.md`'s recognition system.
- Recognition is based on verifiable contribution history, not self-reported claims, informal reputation, or financial contribution.

---

## 4. Authorship Rules

- Authorship credit is attached to a specific, attributable contribution (a commit, a pull request, an accepted content submission) — never assigned speculatively or in anticipation of future work.
- An individual's preferred name or handle is used as they specify it; CeloHT does not alter, embellish, or add unverified credentials to an author's listed identity.
- Co-authorship is recorded following standard Git co-author conventions where multiple individuals contribute to the same artifact.
- Removal from this list occurs only in cases of confirmed fraudulent contribution (e.g., plagiarism or license violation), not as a discretionary or punitive measure disconnected from the contribution record itself.
- This document does not assign authorship to any individual who has not made an actual, recorded contribution, regardless of their role or seniority within CeloHT's governance structure.
