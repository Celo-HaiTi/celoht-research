# Community

## Who Makes Up the CeloHT Community

- **Community members** using CeloHT's education and payment tools
- **Agent Network members** providing local support
- **Open-source contributors** — code, documentation, translation
- **Working Group members and maintainers**
- **Partner organizations** — NGOs, universities, governments, companies
- **Diaspora supporters**
- **Ambassadors** — see [AMBASSADOR_PROGRAM.md](./AMBASSADOR_PROGRAM.md)

## Community Spaces

| Space | Purpose |
|---|---|
| GitHub Discussions | Technical questions, proposals, general discussion |
| Discord | Developer collaboration, real-time chat |
| Telegram | Community and agent coordination |
| Social media | Public updates — see the Brand repository's `SOCIAL_MEDIA_GUIDE.md` |

## Participation Pathways

- **Learn** — complete education modules, no commitment required (see [EDUCATION.md](./EDUCATION.md))
- **Contribute code or docs** — see [CONTRIBUTING.md](./CONTRIBUTING.md)
- **Become an agent** — see [AGENT_NETWORK.md](./AGENT_NETWORK.md#agent-lifecycle)
- **Join a Working Group** — see [WORKING_GROUPS.md](./WORKING_GROUPS.md#joining-a-working-group)
- **Become an ambassador** — see [AMBASSADOR_PROGRAM.md](./AMBASSADOR_PROGRAM.md)
- **Partner your organization** — see [PARTNERS.md](./PARTNERS.md)
