# Community Research

**Summary:** Research on community structure, participation, and trust dynamics across CeloHT's programs.
**Purpose:** Understand the trust-building mechanism CeloHT depends on, not just assume it's working.
**Scope:** Trust formation, community participation patterns, Agent Network social dynamics.
**Audience:** Agent Network Working Group, researchers.

## Overview

CeloHT's core bet is that a trusted local agent succeeds where an app alone would fail (see the main documentation repository's `AGENT_NETWORK.md`). This area studies that trust mechanism directly — how it forms, what strengthens or weakens it, and whether it holds up as the network scales beyond people who know each other personally.

## Research Questions

1. What specifically builds trust in a CeloHT agent — prior relationship, visible verification, word of mouth, something else?
2. Does trust in an individual agent transfer to trust in CeloHT as an institution, or stay strictly personal?
3. How does community trust change as the Agent Network scales beyond small, tightly-connected communities?

## Objectives

Give the Agent Network Working Group evidence on what actually sustains trust, informing expansion strategy.

## Current Knowledge

Foundational stage.

## Data Sources

Planned community trust surveys, qualitative interviews with users and agents.

## Methodology

Primarily qualitative — interviews and field observation. See [../../METHODOLOGY.md](../../METHODOLOGY.md) and [../../FIELD_RESEARCH.md](../../FIELD_RESEARCH.md).

## Limitations

Trust is highly context-dependent; findings from Léogâne's pilot community should be tested, not assumed, in different community contexts.

## Future Work

Baseline community trust survey ahead of Phase 3 multi-region expansion.
