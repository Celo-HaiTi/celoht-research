# CeloHT Messaging Framework

## The One-Sentence Description

**"CeloHT is a Haitian-led, community-governed initiative that makes digital financial tools accessible through education, a local agent network, and environmental sustainability — with no token, no investment, and no affiliation with Celo Foundation or Valora beyond using their open infrastructure."**

## The Elevator Pitch (30 seconds)

CeloHT helps Haitian communities access digital financial tools that were previously out of reach — not by dropping an app on people, but by teaching financial and Web3 literacy in Haitian Creole, training local community agents who provide real human support for cash-to-digital conversion, and reinvesting in the community's environment through reforestation. It's open source, community-governed, and it has no token, no investment product, and no speculative model.

## Message Hierarchy

1. **Primary message:** CeloHT expands financial inclusion in Haiti through education, community, and sustainability — together.
2. **Supporting message A (trust):** CeloHT is community-governed and fully open source — nothing is hidden.
3. **Supporting message B (clarity):** CeloHT is not a token, not an investment, and not officially affiliated with Celo Foundation or Valora.
4. **Supporting message C (impact):** Every pillar — Education, Agent Network, Reforestation — produces measurable, reported impact.

## Audience-Specific Messaging

| Audience | Lead with |
|---|---|
| Community members (Haiti) | Education and Agent Network — human support, in Creole, no jargon |
| Developers / open-source contributors | Transparent governance, clean documentation, real-world impact use case |
| NGOs / universities | Measurable impact metrics, community governance model, sustainability pillar |
| Government / policy partners | Non-affiliation clarity, no-token policy, transparent reporting |
| Media / press | Founder story, community-first model, verifiable reforestation and education numbers |

## Proof Points (always back claims with these)

- Open-source repository and public documentation (github.com/Celo-HT)
- Named, trained agents in the Agent Network — not anonymous accounts
- Verifiable reforestation numbers with long-term monitoring
- Public governance discussions — no closed-door decisions

## Messaging to Avoid

- Any comparison to token launches, ICOs, or "getting in early"
- Overpromising financial outcomes for individuals ("you'll earn," "grow your money")
- Overstating Celo/Valora relationship as a formal partnership
- Framing reforestation as a marketing offset rather than a genuine pillar
