# Reforestation Manual: Planting Methodology

*Detailed operational companion to [../REFORESTATION.md](../REFORESTATION.md). **Status:** this manual describes the designed process for the Phase 2 pilot (see [../ROADMAP.md](../ROADMAP.md#phase-2--validation-2026-q4--2027-q1)) — treat it as the operating plan being stood up, not a description of an already-running, multi-site program.*

## Purpose

This manual gives Reforestation Working Group coordinators and community nursery leads a consistent, science-informed process for planning and executing a planting event — so outcomes are comparable across regions and over time.

## Site Selection

### Criteria
- Land tenure clarity — written or community-recognized permission from the landowner/community authority, documented before any planting
- Soil suitability — basic soil assessment (drainage, compaction, existing vegetation) conducted by a trained coordinator or partner agronomist
- Water access — proximity to a reliable water source for the establishment period (first 12–18 months)
- Community proximity — sites near the community responsible for monitoring, to support the ownership model described in [../REFORESTATION.md](../REFORESTATION.md#long-term-sustainability)

### Site Assessment Record
Every site is logged with: GPS coordinates, area (hectares), current land use, soil notes, water access notes, and named responsible community group — this record feeds directly into [monitoring-and-survival.md](./monitoring-and-survival.md).

## Species Selection

Species are selected in partnership with agricultural/environmental partners (see [../REFORESTATION.md](../REFORESTATION.md#scientific-methodology--partnerships)) based on:

1. **Native or regionally naturalized status** — prioritized to support local ecosystem function
2. **Community utility** — species with fruit, fuelwood, or soil-stabilization value are prioritized where appropriate, since this materially improves long-term community incentive to protect the planting (directly supporting survival rate, not just initial planting count)
3. **Site-appropriate hardiness** — matched to the site assessment (drought tolerance for water-limited sites, etc.)

## Planting Density & Layout

Standard density guidance: 2×2m to 3×3m spacing depending on species canopy target and site erosion-control needs, following partner agronomist guidance per site — density is not applied as a single fixed rule across all sites, since soil and slope conditions vary meaningfully.

## Planting Event Execution

1. **Pre-event:** saplings sourced from community nursery (see [nursery-operations.md](./nursery-operations.md)), site prepared (holes dug to appropriate depth, soil amended if needed)
2. **Event day:** community volunteers (see [volunteer-management.md](./volunteer-management.md)) plant under coordinator supervision, with each planted tree GPS-logged individually or by cluster (dense plantings logged by cluster boundary + count, per [monitoring-and-survival.md](./monitoring-and-survival.md#logging-standard))
3. **Immediate post-planting:** initial watering, basic protective measures (e.g. simple guards against livestock where relevant)

## Data Logged Per Event

- Date, location (GPS), species and quantity, responsible community group, planting method notes, initial photo documentation

This data feeds the "trees planted" metric in [../METRICS.md](../METRICS.md#core-metrics) — always paired with the survival tracking in [monitoring-and-survival.md](./monitoring-and-survival.md), never reported alone.
